Secretary Problem Teaching and Python Resources

Download standard-library Python programs for the classical, postdoc, full-information and last-success optimal stopping problems.

Teaching & Python Resources

These resources accompany The Secretary Problem Site. The programs use only the Python standard library and can run locally or in a Google Colab code cell. All simulations are illustrative: mathematical optimality follows from the exact formulas, not from Monte Carlo experiments.

Classical secretary problem: exact probability and simulation

Download classical_secretary.py

The script computes the exact finite-(n) threshold probabilities, identifies the smallest maximizing threshold, and estimates success using random permutations.

For (r),

\[ P_n(r)=\frac{r}{n}\sum_{j=r}^{n-1}\frac1j, \qquad P_n(0)=\frac1n. \]

Run it in a terminal:

python3 code/classical_secretary.py --n 30 --r 11 --trials 10000 --seed 123
python3 code/classical_secretary.py --self-test

For Colab, download and upload the script, then run !python classical_secretary.py --n 30 --r 11.

Last-success problem: Bruss’s odds theorem

Download last_success_odds.py

For independent Bernoulli observations with (0p_k<1), the code calculates the optimal start index given by the sum-the-odds rule and checks its exact success probability against all deterministic start indices.

python3 code/last_success_odds.py --probabilities 0.2 0.5 0.3 0.4
python3 code/last_success_odds.py --self-test

The calculation uses exact fractions when decimal inputs are supplied; floating-point Monte Carlo is not required.

Postdoc problem: choosing the second-best candidate

Download postdoc_secretary.py

This script solves the finite-horizon postdoc problem using exact rational backward induction. It calculates the conditional stopping reward at each relative rank and returns the optimal decision. The built-in tests compare the resulting policy with exhaustive enumeration of all permutations for small \(n\).

python3 code/postdoc_secretary.py --n 10 --k 5 --rank 2
python3 code/postdoc_secretary.py --self-test

See the interactive postdoc explorer.

Full-information best choice: first-stage thresholds

Download full_information_uniform.py

This program covers the first stopping decision for \(n=2\) or \(n=3\) independent \(U(0,1)\) observations. It evaluates exact rational acceptance and continuation probabilities at any rational first observation \(x\), and reports the analytic acceptance cutoff: \(1/2\) for \(n=2\) or \((1+\sqrt6)/5\) for \(n=3\).

python3 code/full_information_uniform.py --n 3 --x 0.70
python3 code/full_information_uniform.py --self-test

See the interactive full-information explorer. This deliberately focuses on two small horizons so that the displayed decision has a transparent analytical derivation.

Interactive activities

  • Optimal Threshold Explorer: see how the exact success curve changes with (n) and (r).
  • Sequential decision game and simulations: compare mathematical predictions to simulated outcomes.
  • Postdoc decision explorer: use exact dynamic programming to choose rank 2.
  • Full-information first-decision explorer: compare acceptance with continuation for two or three observations.
  • Odds-theorem explorer: vary four Bernoulli success probabilities and inspect the optimal start index.
  • Backward-induction proof: derive optimal decisions from the Bellman recursion.

Suggested classroom exercises

  1. Determine the smallest optimal threshold for (n=10), and verify its exact success probability.
  2. Compare optimal rejection fractions for (n=10,30,100) with (1/e).
  3. Investigate the difference between exact probability and simulated frequency for increasing numbers of trials.
  4. For \(n=5\), derive the postdoc stopping rewards for relative ranks 1 and 2 and verify the backward recursion.
  5. For three iid uniform observations, derive the first-stage continuation function and its stopping cutoff.
  6. For four independent Bernoulli trials, compute the sum-the-odds threshold and enumerate the exact success probabilities of all fixed starting positions.

Check the mathematical examples

Run the complete regression suite with Python’s standard-library unittest:

python3 -m unittest discover -s tests -v

The tests check exact classical thresholds, compare finite postdoc policies with exhaustive permutation enumeration, independently enumerate Bernoulli last-success outcomes, and verify the full-information continuation formulas at representative rational observations. No additional packages are required.
